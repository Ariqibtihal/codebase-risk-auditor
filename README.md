# Codebase Risk Auditor

A reusable ChatGPT skill for auditing software projects across security, authentication, authorization, data privacy, scalability, maintainability, reliability, testing, deployment safety, and production readiness.

## Use Cases

Use this skill to review:

- Web apps
- Mobile apps
- Backend services
- APIs
- Dashboards
- Internal tools
- Full-stack applications
- AI-generated projects
- Database-backed systems

## What It Checks

- Security
- Authentication
- Authorization and access control
- Data privacy
- Input validation
- Business logic integrity
- Scalability
- Database/query performance
- Maintainability
- Type safety
- Reliability
- Performance
- Accessibility
- Testing
- Deployment safety
- Observability
- Backup and recovery
