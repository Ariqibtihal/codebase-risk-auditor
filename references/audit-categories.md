# Audit Categories

Use these categories when performing a full technical audit.

## Core Categories

1. Security
2. Authentication
3. Authorization and access control
4. Data privacy
5. Input validation and sanitization
6. Data integrity and business logic
7. Scalability
8. Database and query performance
9. Maintainability
10. Type safety and data contracts
11. Reliability and error handling
12. Performance
13. Accessibility and usability
14. Testing
15. Deployment safety
16. Observability
17. Backup and recovery

## Severity

High risk issues may cause unauthorized access, data leakage, privilege escalation, broken authentication, broken authorization, destructive data corruption, production outage, secrets leakage, or critical business logic bypass.

Medium risk issues may cause poor scalability, unreliable behavior, inconsistent data, weak validation, missing error handling, hard-to-maintain code, or missing tests for important flows.

Low risk issues include minor duplication, naming inconsistency, minor accessibility gaps, minor performance concerns, documentation gaps, or non-critical cleanup.
